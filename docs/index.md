# Documentation

This index is the entry point for the project documentation. Architecture
documents record the approved design and its implementation requirements;
development documents describe the sequence of work.

- [Decision Register 01](architecture/decisions-01.md),
  [02](architecture/decisions-02.md), and
  [03](architecture/decisions-03.md) record accepted architectural
  decisions and their rationale.
- [Foundation Contract 01](architecture/foundation-contract-01.md) defines
  actionable implementation requirements based on those decisions.
- [Engineering instructions](../AGENTS.md) define engineering and AI
  collaboration instructions.
- [F0 roadmap](development/f0-roadmap.md) defines approved implementation
  scope and sequencing.
- [Vision](vision.md) describes long-term product direction, not a binding
  feature contract.
- [README](../README.md) and this index provide orientation and navigation.

Decision registers, architecture contracts, and applicable engineering
instructions contain binding requirements. The roadmap defines approved
work; the vision describes longer-term aspirations. If binding documents
conflict, report the conflict and request human clarification before acting.
